# Shafiya & Ifroz — Interactive Wedding Invitation

## ✏️ Change names, dates and details
Open **config.js**. Everything you normally need to edit is there:
- Bride name / parents / extra text
- Groom name / parents / extra text
- Nikah date, time, venue, address, Google Maps link
- Valima date, time, venue, address, Google Maps link
- Family / Near & Dear names

## 🎵 Add music
Put your own wedding song in this folder and name it:
`music.mp3`

Music starts after the visitor taps OPEN INVITATION because mobile browsers block automatic audio.

## 🚀 Vercel
Upload all files to GitHub and import the repository into Vercel.
No build command is needed. Framework: **Other**.

## Included interactions
- Curtain opening
- Full-screen mobile/Reel-like sections
- Music button
- Scroll reveal
- Scratch-to-reveal date
- Countdown
- Google Maps buttons
- Animated envelope thank-you ending
